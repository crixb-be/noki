# Security / Seguridad

## English

If you find a security problem in Noki, please **do not open a public issue**. Report it privately using GitHub's
[“Report a vulnerability”](../../security/advisories/new) button (Security tab), or contact the maintainer through the links in the README.
Include what you found, how to reproduce it and the Noki version. I'll answer as soon as I can.

Never share API keys or personal data in issues. Noki stores API keys in the Windows Credential Manager, not in files.

## Español

Si encuentras un problema de seguridad en Noki, por favor **no abras un issue público**. Repórtalo en privado con el botón
[«Report a vulnerability»](../../security/advisories/new) de GitHub (pestaña Security), o escribe a quien mantiene el proyecto por los enlaces del README.
Indica qué encontraste, cómo reproducirlo y la versión de Noki. Responderé en cuanto pueda.

Nunca compartas claves de API ni datos personales en los issues. Noki guarda las claves de API en el Administrador de credenciales de Windows, no en archivos.
